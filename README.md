# amen-portfolio

Personal portfolio website of **Amen Chemengui** — aspiring cybersecurity engineer and web developer.

## What it is

A responsive single-page site built with **HTML**, **CSS** and **JavaScript**, featuring:

- Hero section with intro and call-to-action buttons
- About me
- Skills (chip layout)
- Certificates
- Projects (cards with GitHub links)
- Contact section
- Mobile-friendly navigation with hamburger menu

## View it live

🌐 **https://amen0033.github.io/amen-portfolio/** (published free with GitHub Pages)

## Run locally

Just open `index.html` in a browser — no build step needed.

```
# or serve it locally
python3 -m http.server 8000
```
